Exporting to Xero

The export page writes your sales invoices and credit memos to a file that Xero's sales invoice import reads. Open it from Customers → Xero Sync. It needs the Xero Sync permission, which is set for each user on the Users page.

Set up the mapping first, as described in Xero Sync Settings. Until a default account and a rounding account are chosen, the page shows a reminder.

Checking the documents first

  1. Choose the From and To dates. Both are included.
  2. Untick Include credit memos to export invoices only.
  3. Press Preview.

The preview lists each document with its FreeBooks total, the total Xero will work out from the lines, and any rounding line added to make them equal. A row that needs attention is highlighted, and its Status says why:

  • Unmapped accounts or Unmapped tax rates — the document uses an account or tax rate the settings do not map. It is exported to the default account, or untaxed, which is rarely what you want. Add the mapping and preview again.
  • Total mismatch — the difference is larger than the rounding tolerance, which usually means a Xero tax rate differs from FreeBooks'. A rounding line still makes the total agree, but check the document before relying on it.
  • Discount left untaxed — the products on the document have more than one tax rate, so the discount cannot be split between them. Check the tax in Xero.
  • No payment reference — the invoice is to send its payment reference, but it has not been paid. Its PO number is sent instead.

Downloading the file

Press Download CSV to save the file for the same dates. In Xero, import it from the Sales Invoices page using its import button. Each document arrives as a draft for you to approve.

Xero's import has no separate credit note upload, so a credit memo is written as an invoice with negative quantities, giving it a negative total. The export does not record what it has written, so take care not to import the same documents twice.

When FreeBooks is connected to Xero, the same page can send the documents directly and keep track of what has been sent: see Sending Documents to Xero.
