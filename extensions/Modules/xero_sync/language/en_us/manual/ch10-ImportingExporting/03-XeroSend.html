Sending Documents to Xero

Once FreeBooks is connected to Xero (see Xero Sync Settings), the export page can send invoices and credit memos straight to Xero instead of through a file. FreeBooks then remembers what it has sent, so nothing goes twice, and protects a sent document from changes that would leave Xero's copy out of step.

Sending

  1. Open Customers → Xero Sync, choose the dates and press Preview, as for the CSV file (see Exporting to Xero).
  2. Every document that can be sent is ticked. Untick any you want to leave out.
  3. Press Send ticked documents to Xero. The documents go one at a time, and each row's In Xero column shows the result as it arrives. A document Xero refuses does not stop the rest.

Each document arrives in Xero as a draft, an invoice in Xero's invoices and a credit memo in its credit notes. A product that Xero has no item for yet is added to Xero's items, so the line can name it.

A document with an unmapped account or tax rate cannot be ticked: Xero would book it to the wrong place. Add the mapping, preview again, and send it then. Sending needs edit permission on Xero Sync.

The In Xero column

  • Not sent — FreeBooks has not sent the document.
  • Sent, with the date — Xero holds the document. It cannot be ticked again.
  • Changed since it was sent — the document as it would be sent now differs from what Xero holds, usually because the account or tax rate mapping has changed since. To send it again, release it first.
  • Not sent: with Xero's reason — Xero refused the document. Correct the cause and send it again.
  • Released — see below.

Sent documents are locked

An invoice or credit memo that has been sent shows an In Xero badge beside its number. It can still be opened, printed, emailed and used to raise a credit memo, and changes that do not affect Xero or the tax — the shipping method, for instance — save as usual. FreeBooks refuses to save a change to anything Xero holds or the tax rests on: the customer, the billing or shipping address, the billing email, the number, the date, the reference, the currency or any line. A sent document cannot be deleted either.

To correct a sent document, release it, or raise a credit memo instead.

Releasing a document

Press Release beside a sent document to unlock it. This needs full permission on Xero Sync. The document can then be changed in FreeBooks, and sending it again updates the copy Xero already holds rather than making a second one. The update keeps the status the document has in Xero, so an invoice already approved there stays approved.

The update replaces Xero's copy with FreeBooks' version, so any change made to it in Xero is lost. Xero refuses to change a document it has recorded a payment against, or one that has been voided or deleted there, and the row then shows Xero's reason.

A sale recorded wrongly in a paid or voided Xero document is corrected with a credit memo. Where the Xero document can be deleted instead (Xero deletes drafts and documents awaiting approval), delete it in Xero, then press Unlink from deleted Xero copy and send again: the next send makes a new document. FreeBooks deletes nothing in Xero. Xero matches a send to any document with the same number, so unlinking while the old document is still there either overwrites it, if it is a draft, or is refused, if it is voided or paid.
