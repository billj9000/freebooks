Xero Sync Settings

The settings page tells Xero Sync how FreeBooks and your Xero organisation correspond. Open it from Company → Configuration → Xero Sync, or from the properties icon beside the module in the module list. You need edit permission on Configuration to change it. Press the Save icon to keep your changes.

Xero Connection

To send documents straight to Xero, FreeBooks needs an app registered in Xero's developer portal (developer.xero.com, under My Apps), and a connection made through it. Exporting a CSV file needs neither.

The redirect address is oauth_return.php in FreeBooks' own folder, which comes with FreeBooks itself, so Xero Sync needs a FreeBooks release that includes that file.

  1. In the Xero app's settings, add the address shown as Redirect URI to its redirect URIs, exactly as shown. An app can list several, so one used by another tool can keep its own.
  2. Copy the app's Client id into this page, and its Client secret if it has one. A PKCE app has no secret; leave the field blank. Once saved, the secret is never shown again: leave the field blank to keep it, or tick Remove the saved client secret.
  3. Press Connect to Xero. Xero asks you to log in and to allow access, then returns you here. If your Xero login reaches more than one organisation, choose the one to send documents to.

The page then shows which organisation it is connected to. The connection lasts until it is disconnected here, access is removed in Xero, or it goes unused for 60 days, which is Xero's limit; after that, press Connect again. Changing the client id also ends the connection, because it belongs to the old app. Disconnect ends it in Xero as well as here.

While connected, the account code and tax rate fields below suggest Xero's own accounts and tax rates as you type.

The client secret and the connection's tokens are stored encrypted. The key is a file, xero_sync.key, made automatically in the company's folder under my_files. Anyone with both that file and the database can use the connection, so look after a backup that holds both as you would the Xero login itself. If the file is lost, FreeBooks cannot read the stored tokens and the page shows Not connected; connect again, and enter the client secret again if the app has one.

Documents

  • Home country — a document whose country differs from this one counts as foreign and uses the foreign account codes. Choose None to use the ordinary codes for every document.
  • Country taken from — which address decides the document's country. When that address has no country, the other address is used. When neither has one, the document uses the ordinary codes and is flagged.
  • Days until due — an invoice's due date in Xero is its date plus this many days.
  • Rounding tolerance — any difference between the FreeBooks total and the total Xero will work out is posted to the rounding account. A difference larger than this also flags the document for review, because it usually means a rate or a mapping is wrong rather than a penny of rounding.
  • Use the payment reference as an invoice's reference — sends the reference of the receipt that paid the invoice, such as a card transaction id or a cheque number, as the Xero reference, in place of the customer's PO number. An unpaid invoice sends its PO number and is flagged. Credit memos always send their own reference.

Xero Defaults

  • Default account code — the Xero account used for any FreeBooks account not mapped below. A document that needs it is flagged, so you can add the mapping.
  • Rounding account code — the Xero account for Rounding Adjustment lines.
  • Tax rate for untaxed lines — the name of the Xero tax rate put on a line with no tax, such as an untaxed product, the rounding line or an untaxed discount. In a UK organisation, Xero names it No VAT.

Account Mapping

The table lists the accounts your sales invoices and credit memos have posted product, freight and discount lines to, and any account you have already mapped. Tick Show every account to map an account before it has been used.

For each account, enter the code of the Xero account it posts to. If foreign sales post to a different Xero account, enter that in the foreign column; leave it blank to use the same account for every country. Clear both codes to remove a mapping.

Tax Rate Mapping

For each customer tax rate, enter the matching Xero tax rate's name, exactly as Xero shows it in its tax rate settings, for example 20% (VAT on Income). Use the name, not the short code. Xero charges its own percentage for that rate, not FreeBooks', so keep the two the same or more documents will need a rounding line. A rate left blank is sent untaxed and the document is flagged.

Contact Names

A document is sent under the customer's name as FreeBooks has it. Where the customer has a different name in Xero, enter the FreeBooks name and the Xero name here so that Xero matches the existing contact rather than creating another. Use Add a name for more rows, and clear the Xero name to remove one.
