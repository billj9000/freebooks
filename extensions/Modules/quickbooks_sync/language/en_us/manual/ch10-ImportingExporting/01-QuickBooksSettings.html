QuickBooks Sync Settings

The settings page tells QuickBooks Sync how FreeBooks and your QuickBooks company correspond. Open it from Company → Configuration → QuickBooks Sync, or from the properties icon beside the module in the module list. You need edit permission on Configuration to change it. Press the Save icon to keep your changes.

QuickBooks Connection

To send documents straight to QuickBooks, FreeBooks needs an app registered in Intuit's developer portal (developer.intuit.com), and a connection made through it. Exporting import files needs neither.

An Intuit app has two sets of keys: development keys, which connect only to the free sandbox companies Intuit gives every developer account, and production keys, which connect to real QuickBooks companies once Intuit has approved the app for production. Try the module with a sandbox company first.

  1. In the Intuit app's settings, add the address shown as Redirect URI to its redirect URIs, for the keys you will use, exactly as shown. Intuit accepts a plain http address on localhost for development keys only; production keys need https.
  2. Choose the Environment the keys belong to: Sandbox for development keys, Production for production keys.
  3. Copy the app's Client id and Client secret into this page. Once saved, the secret is never shown again: leave the field blank to keep it, or tick Remove the saved client secret.
  4. Press Connect to QuickBooks. Intuit asks you to sign in, choose the company to send documents to and allow access, then returns you here.

The page then shows which company it is connected to. The connection lasts until it is disconnected here, access is removed in QuickBooks, or QuickBooks Sync goes unused for 100 days, which is Intuit's limit; the page shows the date it would lapse. After that, press Connect again. Changing the environment or the client id also ends the connection, because the keys belong to another app or environment. Disconnect ends it at Intuit as well as here.

While connected, the item, account and VAT code fields below suggest QuickBooks' own as you type.

The client secret and the connection's tokens are stored encrypted. The key is a file, quickbooks_sync.key, made automatically in the company's folder under my_files. Anyone with both that file and the database can use the connection, so look after a backup that holds both as you would the QuickBooks login itself. If the file is lost, FreeBooks cannot read the stored tokens and the page shows Not connected; enter the client secret again and connect again.

In QuickBooks first

  • VAT must be turned on in the QuickBooks company.
  • Create a product or service for each income account your sales post to, of the type Service or Non-inventory, with its income account set. FreeBooks keeps the stock, so the items need not track quantities.
  • To keep FreeBooks' invoice and credit memo numbers, switch on Custom transaction numbers in QuickBooks' sales settings.

Documents

  • Home country — a document whose country differs from this one counts as foreign and uses the foreign items. Choose None to use the ordinary items for every document.
  • Country taken from — which address decides the document's country. When that address has no country, the other address is used. When neither has one, the document uses the ordinary items and is flagged.
  • Days until due — an invoice's due date in QuickBooks is its date plus this many days.
  • Rounding tolerance — a penny between the VAT worked out for each VAT code and the VAT FreeBooks saved is taken into the largest VAT line, and a difference in the total is made up with a rounding line. A difference larger than this also flags the document for review, because it usually means a rate or a mapping is wrong rather than a penny of rounding.
  • Use the payment reference as an invoice's reference — sends the reference of the receipt that paid the invoice, such as a card transaction id or a cheque number, in place of the customer's PO number. An unpaid invoice sends its PO number and is flagged. Credit memos always send their own reference. QuickBooks keeps the reference in the invoice's statement memo, which the customer does not see.

QuickBooks Defaults

  • Default item — the QuickBooks product or service used for any FreeBooks account not mapped below. A document that needs it is flagged, so you can add the mapping.
  • Rounding item — the product or service for Rounding Adjustment lines. Set it up in QuickBooks to post to the account you keep rounding differences in.
  • Discount account — the QuickBooks account a document's discount is posted to. Leave it blank to use QuickBooks' own discount account.
  • VAT code for untaxed lines — the name of the QuickBooks VAT code put on a line with no VAT, such as an untaxed product or the rounding line. In a UK company, QuickBooks names it No VAT.

Item Mapping

The table lists the accounts your sales invoices and credit memos have posted product and freight lines to, and any account you have already mapped. Tick Show every account to map an account before it has been used.

For each account, enter the name of the QuickBooks product or service its lines are sold as, exactly as QuickBooks shows it. If foreign sales post to a different account, enter a second item, set up to post there, in the foreign column; leave it blank to use the same item for every country. Clear both names to remove a mapping.

VAT Code Mapping

For each customer tax rate, enter the matching QuickBooks VAT code's name, exactly as QuickBooks shows it, for example 20.0% S. The document carries the VAT FreeBooks charged, so keep each code's rate the same as FreeBooks'. A rate left blank is sent as untaxed and the document is flagged.

Customer Names

A document is sent under the customer's name as FreeBooks has it. Where the customer has a different name in QuickBooks, enter the FreeBooks name and the QuickBooks name here so that the document goes to the existing customer rather than a new one. Use Add a name for more rows, and clear the QuickBooks name to remove one.
