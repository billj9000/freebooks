Settings and Caching

Settings live under Company > Configuration > VIN Lookup. Access to this page, and to using the tool itself, is controlled by its own permission — grant it to a role or user under Roles/Users like any other module.

Settings fields

  • API key — your Vehicle Data Global bearer token. This is separate from the API key used for postcode lookup elsewhere in FreeBooks, even though both talk to the same provider account.
  • Data package(s) — the provider's packageName value for this request, e.g. VehicleDetails. This determines which fields come back and what the lookup costs; change it to match what your Vehicle Data Global account is licensed for.
  • API endpoint — the provider URL. Only change this if Vehicle Data Global instructs you to.

Test Connection

Before saving, enter a real registration number next to Test Connection and click Test. This calls the provider directly with the values currently in the form (even if unsaved) and reports success or the exact error and HTTP status returned, which is the fastest way to confirm the key and package name are correct.

How caching works

  • A successful lookup is stored against its registration number and never expires on its own — there is no time-based cache expiry.
  • A failed lookup (bad key, registration not found, provider error) is never cached, so it will always retry against the provider next time.
  • Use Refresh from Provider on the results page to force a fresh lookup and overwrite the cached copy for that registration.
  • Deleting a row from Recent Lookups also forces the next lookup for that registration to go back to the provider.
  • Users with full access to VIN Lookup additionally see a raw JSON panel under each result, useful for confirming exactly what the provider returned.
