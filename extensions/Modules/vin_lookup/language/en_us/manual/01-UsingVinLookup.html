Using VIN Lookup

Go to Tools > VIN Lookup. Type a UK registration number into the Registration Number field and either press Enter or click Look Up. Spaces and letter case are ignored, so ab12 cde and AB12CDE are treated the same.

Reading the results

  • The VIN row shows the vehicle's Vehicle Identification Number with a Copy button next to it, so it can be pasted straight into another record.
  • If the account is not licensed to return VINs, or the provider has none on file, the row reads VIN not available for this vehicle instead of a copy button.
  • A note above the VIN shows whether the result was Fetched from provider (a brand-new lookup) or Cached, along with the date it was first fetched and how many times it has been viewed since.
  • Every other field the provider returned is grouped into labeled sections below the VIN — make, model, colour, registration dates, MOT status, and anything else your data package covers.

Refreshing a cached result

Lookups are cached indefinitely to avoid paying for the same registration twice. If you need the very latest data for a vehicle — for example after a keeper change — click Refresh from Provider next to the result. This re-queries Vehicle Data Global and overwrites the cached copy.

Recent Lookups

The Recent Lookups table at the bottom of the page lists every registration that has been searched, most recently used first. Click View to redisplay a cached result without re-typing the registration. Users with full access to this tool can also Delete a row, which removes it from the cache so the next lookup fetches fresh data from the provider.
