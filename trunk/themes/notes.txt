Colour schemes

A theme is a directory under themes/ (FreeBooks ships one, default). Each colour scheme is a
directory under themes/THEME/css/, and every directory there appears in the Select Color Scheme
list on Company > My Profile. The default scheme is start (DEFAULT_COLORS).

A scheme directory holds:

stylesheet.css  Required. Linked first on every page, before Bootstrap and
                ext/bootstrap5/freebooks.css, so it can set only the base page: background, text
                colour and font, fieldsets, labels.
theme.css       Optional. Linked after Bootstrap and freebooks.css (html_theme_stylesheet()). A
                scheme without one looks like start apart from its stylesheet.css.

Every colour, background image, font, text size and corner radius in ext/bootstrap5/freebooks.css
is read from a --fb-* token, and the list of tokens, with start's values, is at the top of that
file. A theme.css changes the look mainly by redefining those tokens on :root; it needs rules of
its own only for what a token does not cover - spacing, weights, a border's shape, or a part it
colours differently from the rest of its group. An image token is a whole background-image value:
give "none" or a path from the web root, because browsers differ on which stylesheet a relative
url() inside a variable is resolved against.

To add a scheme, copy themes/default/css/refresh/ to a new directory name and edit both files.
Fonts and images go under ext/ or inside the scheme directory and are referenced by relative URL;
nothing is fetched from a CDN.

A user whose saved scheme is no longer installed is shown start.
