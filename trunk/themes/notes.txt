Colour schemes

A theme is a directory under themes/ (FreeBooks ships one, default), holding the shared page parts,
icons and images. Each colour scheme - what users choose as their theme - is a directory under
themes/THEME/css/, and every directory there appears in the Select Theme list on Company > My
Profile, the default scheme first and the rest by name. The default scheme is start (DEFAULT_COLORS).

A scheme directory holds:

theme.json      Optional. The name shown in the list and a one-line description shown under it:
                  { "name":        { "en_us": "Refresh", "nl_nl": "..." },
                    "description": { "en_us": "A flatter, lighter look ...", "nl_nl": "..." } }
                Each value is a plain string or strings keyed by language code; the user's
                language is used, else en_us. Without it the list shows the directory name and no
                description. "dark": true makes the scheme a dark one (see Dark schemes below).
stylesheet.css  Required, except in a scheme that follows the browser (see below). Linked first on every page, before Bootstrap and
                ext/bootstrap5/freebooks.css, so it can set only the base page: background, text
                colour and font, fieldsets, labels.
theme.css       Optional. Linked after Bootstrap and freebooks.css (html_theme_stylesheet()). A
                scheme without one looks like start apart from its stylesheet.css.

Every colour, background image, font, text size and corner radius in ext/bootstrap5/freebooks.css
is read from a --fb-* token, and the list of tokens, with start's values, is at the top of that
file. A theme.css changes the look mainly by redefining those tokens on :root; it needs rules of
its own only for what a token does not cover - spacing, weights, a border's shape, or a part it
colours differently from the rest of its group. An image token is a whole background-image value:
give "none" or a path from the web root, because browsers differ on which stylesheet a relative
url() inside a variable is resolved against.

A scheme can also replace how parts of every page are drawn, by carrying its own copy of any of
these files; theme_file() uses the scheme's copy if there is one and the theme's otherwise:

layout.php      Everything inside <body>: the menu, the page and the footer.
menu.php        The main menu (a navbar across the top in the default).
footer.php      The logo, company and version line under every page.
toolbar.php     The buttons of a page toolbar (icons in the default). A scheme that wants buttons
                with an icon and a label includes themes/default/toolbar_labelled.php from its
                own toolbar.php, as refresh and workspace do.

workspace is the example of a scheme replacing the frame: its layout.php and menu.php draw a
sidebar menu and a top bar with a breadcrumb in place of the navbar.

Each default file in themes/default/ states in its header what it is given and what pages and
their scripts rely on it keeping - for the toolbar, the button ids and the div they sit in. The
menu's sorting and permission checks are shared functions in includes/common_functions.php
(fbmenu_sort, fbmenu_permitted, fbmenu_item_permitted), so a replacement menu draws only markup.
The pop-up windows that draw a whole page themselves (Help, the shipping label viewers, the
packing list) do not use these files.

Dark schemes

A scheme whose theme.json has "dark": true is drawn in dark mode: html_color_mode() puts
data-bs-theme="dark" on every page's <html> tag, which turns Bootstrap's own components dark,
and the [data-bs-theme=dark] rules at the end of ext/bootstrap5/freebooks.css cover what pages
and scripts colour for themselves - Bootstrap's always-light table and background classes, a
status colour a script paints behind a field, a company's own footer logo. The scheme's theme.css must set
every token, because start's values are all for a light page, and sets them on
":root, [data-bs-theme=dark]" so they outrank Bootstrap's own dark values. Help topics, which
are pages of their own, take the scheme's tokens through
modules/phreehelp/style_sheet/manual_dark.css. Anything that stands for paper - the Forms
canvas, a printed document - keeps a white ground: give it the class fb-paper. ledger-dark is
the example.

Schemes that follow the browser

A scheme whose theme.json names two other schemes instead of carrying files of its own follows
the browser's (normally the system's) light or dark setting:
                  { "name": ..., "description": ..., "light": "refresh", "dark": "ledger-dark" }
Every page links both partners' stylesheet.css and theme.css, each with the media query of the
mode it serves, so the browser applies one and switches the moment the setting changes; a
browser that reports no setting gets the light one. A script in the head (html_theme_stylesheet())
keeps data-bs-theme on <html> in step and fires 'fb-color-mode' on the document after each
change, which the Help window and the HTML editors listen for. layout.php, menu.php, footer.php
and toolbar.php come from the light partner, so the two partners must draw the same frame. Each
partner must be an ordinary scheme, not another pair; without both, the pair is drawn as its light
partner, or as the default. auto (Refresh / Ledger Dark) and workspace-auto (Workspace / Workspace
Dark) are the examples; workspace-dark shows a dark partner reusing its light partner's frame, its
layout.php and menu.php each including Workspace's. theme_schemes() in
includes/common_functions.php resolves a scheme to the schemes it draws with.

A page that sets a colour of its own does it through a token with the old colour as fallback
(var(--fb-line, #a6c9e2)), or adds a [data-bs-theme=dark] rule beside it, so that it follows
a dark scheme and start is unchanged.

To add a scheme, copy themes/default/css/refresh/ to a new directory name and edit its files,
starting with the name and description in theme.json. Fonts and images go under ext/ or inside the
scheme directory and are referenced by relative URL; nothing is fetched from a CDN.

A user whose saved scheme is no longer installed is shown start.
