Setting up Multiple Locations (Branches)

FreeBooks supports multiple branches/stores. Multi-branch support must first be turned on (Company > Configuration, Enable multiple branch functionality); once enabled, a Branch item appears under the Company menu. Branches are managed as a contact type, using the same form/list UI as Customers, Vendors, and Employees.

To enter a new branch:

  1. Select Company->Branch->New Branch, or Company->Branch to see the branch list and press the Add button.
  2. Enter a branch ID. Branch ID's should not contain spaces or special characters. It is best to use an abbreviation or store number as the Branch ID.
  3. Enter the Branch information requested by the form. Required information is identifed by a * next to the input box.
  4. Press the Save button to save the record.

To delete a branch:

  1. Select Company->Branch.
  2. The current branches are listed. To delete a branch, select the delete icon for the branch to delete.
  3. Confirm the deletion of the record. NOTE: If the branch is used in a journal record, it cannot be deleted. Instead, check the inactive box and the branch will not be shown on the pull down menus for the order forms.
