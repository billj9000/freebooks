Email Settings

Email settings are configured in General Admin › Email. FreeBooks uses PHPMailer for all outgoing mail and supports several transport methods.

Transport Methods

TransportWhen to use
PHP mail() Uses the server's local MTA (sendmail/Postfix). Suitable only when a properly configured MTA is present on the server.
sendmail / sendmail -f Calls the sendmail binary directly. Use sendmail -f to set the envelope sender, which can help with SPF checks.
SMTP (no auth) Connects to an SMTP relay that does not require authentication (e.g. an internal mail gateway or a relay configured to accept connections from your server's IP).
SMTP with authentication Connects to an SMTP server with a username and password. Suitable for most traditional hosting providers and for Gmail/Office 365 App Passwords.
SMTP with OAuth2 Connects using OAuth2 (XOAUTH2 mechanism). Required for Gmail and Office 365 when legacy authentication is disabled. See OAuth2 Setup.

Encryption Settings

  • None — plain SMTP, no encryption (port 25). Suitable for internal relays only.
  • STARTTLS — starts a plain connection then upgrades to TLS. Standard for most providers (port 587).
  • SSL/TLS — TLS from the start (port 465). Used by some hosts and by Office 365 legacy SMTP.
