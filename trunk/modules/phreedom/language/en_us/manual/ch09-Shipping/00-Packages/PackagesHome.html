Shipping - Packages

Shipping Packages are reusable box/carton definitions — code, name, weight, capacity, and dimensions — that carrier modules capable of automatic box-packing (DHL Express and Royal Mail) use to work out which box or boxes a shipment needs, based on the dimensions and weight recorded on each inventory item. A package can be restricted to a single carrier or left available to all of them.

Creating a Package

  1. From the main menu, select Tools->Shipping Packages.
  2. Press New.
  3. Enter a Code and a Name for the package.
  4. Optionally enter a Description.
  5. Select a Carrier, or leave it as All Carriers so any carrier's box-packing can use it.
  6. Enter the package's own Tare Weight (how much the empty box weighs) and, if the carrier needs it, a Max Weight capacity.
  7. Enter External dimensions (the box's outside length/width/height) and, if known, Internal dimensions (the usable packing space). Vol. Weight (volumetric/dimensional weight) is calculated automatically from the External dimensions as they're entered.
  8. Optionally enter a Cost for the box itself, and a Sort Order to control where it appears in lists and how it's tried first during box-packing.
  9. Press Save.

NOTE: The Code must be unique across all packages, regardless of carrier.

Editing or Deleting a Package

  1. From Tools->Shipping Packages, optionally use the Carrier filter to narrow the list.
  2. Click a row to open it for editing, make changes, and press Save; or press the Delete icon on a row to remove it.
  3. Check Inactive instead of deleting to keep a package out of box-packing and new lists without losing its history on past shipments.

How Packages Are Used

When a carrier module that supports automatic box-packing needs to know what a shipment will ship in — for example, DHL Express when quoting a rate — it packs the order's line items into the active packages available to that carrier (its own carrier-specific packages plus any marked All Carriers), and uses the resulting box or boxes for the rate request or label. Each inventory item needs its own weight and dimensions recorded on the item record for this to work:

  • Items with no dimensions recorded are left out of the box-packing itself, but their weight is still added to the total; a caution message lists which SKUs were affected.
  • Items that don't fit in any available package are also flagged with a caution message, listing the affected SKUs, so packages can be added or adjusted to cover them.
