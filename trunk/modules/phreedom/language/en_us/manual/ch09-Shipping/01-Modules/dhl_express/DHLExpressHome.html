Shipping Modules - DHL Express

FreeBooks includes a shipping module for DHL Express using the MyDHL API. The module supports international and domestic rate queries, label generation for multi-package shipments, customs export declarations, and shipment cancellation directly from the invoice list.

A DHL Express account and API credentials are required. Credentials are obtained from the DHL Developer Portal.

Features

  • Real-time rate quotes from within the order/invoice form
  • Label generation for all DHL Express service levels (Worldwide, 9:00, 10:30, 12:00, Domestic, Economy Select, etc.)
  • Multi-package shipments
  • Automatic customs / export declaration for international shipments
  • Shipment cancellation via the DHL API
  • Label reprint from the Shipment Details popup
  • Test (sandbox) and Production modes

Prerequisites

  1. A DHL Express account number.
  2. MyDHL API credentials (API key and API secret) from the DHL Developer Portal. Separate credentials exist for the sandbox (Test) and live (Production) environments.
  3. Company address fields completed in Admin → Company Information (postal code, city, and country are sent to DHL as the ship-from address).

Installation

  1. Go to Setup → Shipping Settings.
  2. Locate the DHL Express row and click Install.
  3. Click the DHL Express row again and click Edit.
  4. Enter your API Key, API Secret, and DHL Account Number.
  5. Set Mode to Test to use the sandbox, or Production for live shipments.
  6. Click Update.

International Compliance Settings (EORI / IOSS)

Shipper EORI and IOSS numbers are configured in Setup → Shipping Settings → General → International Compliance.

  • Shipper EORI Number — sent to DHL on every international shipment as a shipper registration number. Required for exporting from the UK or EU.
  • Shipper IOSS Number — stored for reference only. Because DHL does not currently provide a per-shipment IOSS field in the MyDHL API, the IOSS number must be registered directly on your DHL account at mydhl.express.dhl. Once registered on the account, DHL applies it automatically to eligible EU import shipments (goods valued below €150).

Getting a Rate Quote

  1. Open a sales invoice or order.
  2. Click the Shipping Estimator button next to the freight method field.
  3. Verify or update the destination address and package details, then click Next.
  4. Available DHL Express services and rates are listed. Click the desired rate to populate the carrier, service, and cost on the order; the popup closes automatically.

Printing a Label

  1. Post (save) the invoice first. The invoice must be in posted state before a label can be generated.
  2. In Customers → Invoice Manager, locate the invoice and click the Ship (truck) icon on its row.
  3. A label manager popup opens with recipient address and shipment details pre-filled from the invoice.
  4. Review and adjust the following fields as needed:
    • Ship Date — defaults to today. DHL will advance to the next business day if the request is made after noon UTC.
    • Service Type — select the DHL Express service level.
    • Package Details — enter weight and dimensions for each package. Click the + icon to add packages for multi-piece shipments.
    • Customs / Export Information — shown automatically for international destinations. Complete the Goods Description, Declared Value, HS/Commodity Code, Country of Origin, and Reason for Export.
  5. Click Print Label. The label PDF is retrieved from DHL and stored on the server; the label viewer opens automatically.
  6. Print the label from the viewer. Close the popup when done.

Reprinting a Label

  1. In Invoice Manager, click the View Shipment (log) icon on the invoice row. The Shipment Details popup opens.
  2. Click Reprint Label in the toolbar. The stored PDF is displayed without contacting DHL again.

Cancelling a Shipment

  1. In Invoice Manager, click the View Shipment icon on the invoice row. The Shipment Details popup opens.
  2. Click the Delete (bin) icon in the toolbar.
  3. A confirmation dialog warns that the shipment will be cancelled at DHL. Confirm to proceed.
  4. FreeBooks sends a cancellation request to the DHL API, deletes the stored label file, and removes the shipment log entry. The invoice row reverts to the Ship state and can be re-shipped if required.

Note: DHL Express cancellations are subject to DHL's own cut-off rules. Shipments that have already been collected by DHL may not be cancellable via the API.
