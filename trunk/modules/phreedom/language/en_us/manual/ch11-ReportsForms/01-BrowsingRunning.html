Browsing and Running Reports and Forms

The Home tab

Opening Reports and Forms lands on a Home tab with two lists: My Reports (reports you've personally saved or favorited) and Recently Added (the newest reports and forms available to you).

Browsing folders

Reports and forms are organized into folders, much like a file browser. Click a folder to open it; a breadcrumb at the top lets you navigate back up. Each row shows an icon indicating whether it's a folder, a report, or a form. Use the search box to filter the current list by title. An empty folder can be deleted; folders containing reports or forms cannot.

Opening a report or form

Selecting a report or form shows its details — type (Report or Form), group, creation date, and last update — along with a toolbar:

  • Open/Run — runs the report or form.
  • Edit/Design — opens it in the designer (requires an elevated permission level; see Designing Reports and Forms).
  • Rename, Copy, and Delete — each requiring a corresponding permission level.
  • Export — downloads the report or form's definition as a zipped XML file, for backup or transfer to another company.

Running a report

Running a report presents up to three tabs:

  • Criteria — filters for this run (a date/period range, an account, a status, etc., depending on how the report was designed).
  • Fields — lets you re-pick, reorder, or resize the columns for this run only, without changing the saved report design.
  • Page Setup — lets you override paper size, margins, and fonts for this run only.

A report can be exported as PDF, CSV, XML, or HTML.

Running a form

Forms only present a Criteria tab (and only when more than one form could apply — see below) and always produce a PDF.

Many places in FreeBooks that print or email a specific document — an invoice, a packing slip, a check — open a form directly for that one record rather than making you browse for it. If more than one form is available for that document type, you're asked to pick which one; if only one exists, it opens automatically with no picker shown.

Saving a personalized copy

After running a report, you can save your current Criteria/Fields/Page Setup choices as your own personal copy, without changing the original shared report that everyone else uses.

Viewing vs. emailing

Output can be viewed/downloaded directly in the browser, or emailed. When emailing, the subject and body default to a template that can include the report or form's own title, the current date, and your company name, and both are editable before sending.

Where the Forms engine lists things

The Forms engine keeps reports and forms on two separate pages, because almost nothing you can do to one applies to the other.

  • Tools → Reports (Forms) lists reports, which you run as a PDF or a CSV, email, and edit. They are grouped under the area they belong to — Customers, Vendors, General Ledger, Inventory and so on.
  • Tools → Form Layout lists forms, grouped by folder: Invoices/Packing Slips, Purchase Orders, Customer Statements, Bank Checks. That page is for laying a form out, so it needs permission to write documents.

A form is not run from a list at all. It prints one record at a time, so you open it from the document it belongs to — the order, invoice or statement — and use that document's own Print button. Listing forms beside reports only ever offered a button that could not know which record you meant.

Finding a report

The list is grouped under the area each report belongs to. Click a heading to fold that group away, and type in the Filter by name box above the list to narrow it to the reports whose name or group contains what you typed. Filtering looks inside folded groups as well, so a report you are searching for is never hidden by a group that happens to be shut.

Running a report

The PDF button beside a report runs it straight away, exactly as its author drew it — over the date range the report itself specifies. The arrow beside that button offers the rest:

  • CSV — the same report as a spreadsheet file rather than a page.
  • Email — sends it as a PDF attachment.
  • Options — runs it over a different date range, accounting period or account, for this one run only. Nothing you choose here is saved to the report.

Options only appears on reports that have something to ask. A report with no date field in it runs the same whatever range you name, so it is not offered one. The date choice starts at As the report is set, which names the range the report was designed with — leave it alone and the report runs as designed.

The bank reconciliation is the one report that cannot run until you answer: it has to be told which account to reconcile, so the options open by themselves and the account is asked for before anything is produced.

If you can write reports as well as run them, each row also shows the dataset or calculation that serves it, under the name. That is the answer to “why can this report not see that field”. Everybody sees a warning beside any report the Forms engine cannot serve, with the reason.

To email a report, choose Email from that same menu. The dialog opens with the report's name at the top, the run options in it, and the message below, so what is sent covers exactly what the options ask for — a report emailed and the same report downloaded always cover the same ground. Leave the subject empty to send it under the report's own name.

Five address fields are offered, on reports and on forms alike:

  • From — defaults to your own address, so replies come back to you rather than to the company's general mailbox. Change it if the reply should go elsewhere.
  • To and To name — the recipient. On a form printed from an invoice or order, the customer's address is filled in for you.
  • CC — copied openly; every recipient sees this address.
  • BCC — copied privately. Nobody else on the message sees it, which is the one to use for keeping your own copy of what was sent.

Leave CC or BCC empty if you do not need them. If the message cannot be sent, the page says why and keeps everything you typed, so only the mistake needs correcting.

Worked example: printing or emailing a customer invoice

From the Sales/Invoice screen, the invoice's own print/email button opens Reports and Forms already scoped to that one invoice record and automatically selects the correct invoice form (skipping the picker if only one invoice form is defined). If you choose to email it, the customer's billing name and email address are filled in automatically from the invoice. The Save icon on the invoice form's toolbar renders the PDF and either displays it or sends the email, depending on which button was pressed.
