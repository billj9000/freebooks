Browsing and Running Reports

Where things are listed

Reports and forms are kept on two separate pages, because almost nothing you can do to one applies to the other.

  • Tools → Reports lists reports — the ones you run as a PDF or a spreadsheet, email, and edit. They are grouped under the area they belong to: Customers, Vendors, General Ledger, Inventory and so on.
  • Tools → Form Layout lists forms, grouped by folder: Invoices and Packing Slips, Purchase Orders, Customer Statements, Bank Cheques. That page is for laying a form out, so it needs permission to write documents.

A form is not run from a list at all. It prints one record at a time, so you open it from the document it belongs to — the order, invoice or statement — and use that document's own Print button. See The Print Buttons and Printing a Document You Have Open. Listing forms beside reports only ever offered a button that could not know which record you meant.

Finding a report

Click a group heading to fold that group away, and type in the Filter by name box above the list to narrow it to the reports whose name or group contains what you typed. Filtering looks inside folded groups as well, so a report you are searching for is never hidden by a group that happens to be shut.

Running a report

The PDF button beside a report runs it straight away, exactly as its author drew it — over the date range the report itself specifies. The arrow beside that button offers the rest:

  • CSV — the same report as a spreadsheet file rather than a page.
  • Email… — sends it as a PDF attachment.
  • Options… — runs it over a different date range, accounting period or account, for this one run only. Nothing you choose here is saved to the report.

Options only appears on reports that have something to ask. A report with no date field in it runs the same whatever range you name, so it is not offered one. The date choice starts at As the report is set, which names the range the report was designed with — leave it alone and the report runs as designed.

The bank reconciliation is the one report that cannot run until you answer: it has to be told which account to reconcile, so the options open by themselves and the account is asked for before anything is produced.

If you can write reports as well as run them, each row also shows the dataset or calculation that serves it, under the name. That is the answer to “why can this report not see that field”. Everybody sees a warning beside any report that cannot be served, with the reason.

Emailing a report

Choose Email… from that same menu. The dialog opens with the report's name at the top, the run options in it, and the message below, so what is sent covers exactly what the options ask for — a report emailed and the same report downloaded always cover the same ground. Leave the subject empty to send it under the report's own name.

Five address fields are offered, on reports and on forms alike:

  • From — defaults to your own address, so replies come back to you rather than to the company's general mailbox. Change it if the reply should go elsewhere.
  • To and To name — the recipient. On a form printed from an invoice or order, the customer's address is filled in for you.
  • CC — copied openly; every recipient sees this address.
  • BCC — copied privately. Nobody else on the message sees it, which is the one to use for keeping your own copy of what was sent.

Leave CC or BCC empty if you do not need them. If the message cannot be sent, the page says why and keeps everything you typed, so only the mistake needs correcting.

Creating and changing reports

Running a report and writing one are separate permissions, so these buttons appear only for a role that holds the second. Where they do:

  • New, above the list, starts an empty report. To start from one that is nearly right, copy that instead.
  • Copy beside a report duplicates it, leaving the original alone. This is the safe way to alter a shipped report: change the copy, and an upgrade cannot overwrite your work.
  • Edit opens it in the report editor — see Editing a Report.
  • Delete is shown at the highest permission level only.

Forms are changed the same way but on their own page, with the layout editor rather than the report editor: Changing a Form's Layout.
