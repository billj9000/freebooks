Reports and Forms Settings

Module-wide settings for Reports and Forms (as opposed to settings on an individual report or form) are found in its admin settings, under three tabs.

General

Defaults applied to newly-created reports and forms (each can still be overridden per-report):

  • Default column width and page margin.
  • Default text for the two title lines (for example, defaulting to the report's own name and a "Report Generated" date line).
  • Default paper size and orientation.
  • Name-trim length used when listing reports and forms in the folder browser.
  • Heading row spacing.
  • PDF engine — FPDF (lighter, the default) or TCPDF. TCPDF is required for UTF-8 text and for bar codes; if a form uses a bar code element, TCPDF must be selected here.

Stats

Usage statistics for reports and forms.

Tools

A structure verification/rebuild utility: it re-scans the reports and forms folder structure, clears out any database entries that no longer have a matching saved file, and moves any orphaned reports or forms it finds into a Miscellaneous folder rather than losing them.

Re-stamp Paper Size rewrites the page size of every stored report and form to the default paper size set on the General tab. The default above applies only to reports created after it is changed; this is what moves the ones already installed. See Paper Size.
