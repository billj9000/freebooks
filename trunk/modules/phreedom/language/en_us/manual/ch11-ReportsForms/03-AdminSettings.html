Reports and Forms Settings

Settings that apply to the whole module — as opposed to settings on an individual report or form — live on the Forms Module Settings page. Go to Company → Module Administration and click the properties icon beside Forms Module.

Settings

Each of these is a fallback. A report or form that states its own value keeps it; these apply only where the document is silent.

  • Default paper size — the paper a document sits on when its own layout does not say. Changing it affects documents created afterwards; to move the ones already installed, use Re-stamp Paper Size below. See Paper Size.
  • Row spacing — extra space between the rows of a report table, in points. The shipped value is 2.
  • Default column width — width in millimetres for a report column whose definition declares none. The shipped value is 25.

The page also carries a reminder that printing requires the Forms — run and print documents permission, which is not set here but under Company → User Security. See The Print Buttons.

Tools

Two maintenance actions, shown only to a role that could use them. Both ask for confirmation first.

Re-stamp Paper Size re-targets every stored report and form onto the current default paper size. Element positions are not moved, so a form drawn for a wider page will sit closer to the right edge on a narrower one — worth checking a form or two afterwards. Any file whose page setting cannot be located is left untouched, and it tells you how many there were.

Document List Verification / Rebuild rebuilds the document list from the definition files on disk. It reloads the folder structure, re-files any document whose folder has gone missing, and clears list entries that no longer have a file behind them. Use it after a restore has left the list disagreeing with what is actually stored.
