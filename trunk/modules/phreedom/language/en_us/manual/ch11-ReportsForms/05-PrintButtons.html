The Print Buttons

Every document in FreeBooks that can be printed carries a Print button, and they all behave the same way: sales orders, quotes, invoices, credit memos, purchase orders, bills, cheques, deposits, POS receipts and work orders.

Pressing one opens a small print window for that document. What you do there — choose a layout where the document type has more than one, then view, download or email it — is described in Printing a Document You Have Open.

Printing several at once

Some lists let you print a batch rather than one document. On the Sales Invoice Manager you can tick invoices, or use Select All Unprinted to tick the ones that have never been printed, and then press Print Selected. The result is one document containing all of them, one after another.

What is printed

A Print button asks for a kind of document rather than a particular layout — "an invoice", not "invoice number four". Which layouts exist for that kind is up to your company: the shipped ones are there from installation, and you can add your own. Where more than one exists you are asked which to use; where only one does, it is used without asking.

If no layout at all is defined for a document type, its Print button has nothing to open. That is worth knowing when a button appears to do nothing: the place to look is the document list under Reports and Forms, not the button.

Permission

Printing requires the Forms — run and print documents permission. Anyone whose role does not grant it cannot open a document from a Print button, so if some staff can print and others cannot, that permission is the reason. Roles are set under Company → User Security.

It is a separate permission from the right to see or change the document itself. Printing does not alter what it prints, so a role set to Read Only for invoices can still print one — provided it also carries the printing permission above.
