Which Engine the Print Buttons Use

FreeBooks has two printing engines while the newer one is being proven: the original, and the Forms module. Both read the same stored form definitions, so an invoice looks the same whichever prints it. Until you say otherwise, every Print button keeps using the original.

Turning it on

Go to Company → Module Administration, click the properties icon beside Forms Module, and set Print buttons open Forms to Yes.

The setting is per company, and it takes effect immediately — the next Print button you click opens Forms. Setting it back to No restores the original engine just as quickly. Nothing is converted or moved either way, so there is no cost to trying it and no work to undo.

It affects every Print button in the program at once: sales orders, quotes, invoices, credit memos, purchase orders, bills, cheques, deposits, POS receipts and work orders.

Who it applies to

Printing through Forms requires the Forms — run and print documents permission. Anyone whose role does not grant it carries on printing through the original engine, even with the setting on, so nobody loses the ability to print. If you turn the setting on and some staff still see the old print window, that permission is the reason — grant it to their role under Company → User Security.

What is different

The Forms print window asks the same thing of you and offers the same three choices: view the document, download it, or email it to the customer. Two differences are worth knowing about:

  • Where a document type has several forms — several invoice layouts, say — Forms lists them and you pick one, rather than pre-selecting a layout for you.
  • If part of a form cannot be produced, Forms says so at the top of the window instead of printing the document with a field silently missing.

Before you switch everyone over

Print one of each document you rely on and compare it with the same document printed the old way. Invoices, purchase orders and anything on pre-printed stationery are the ones to check, since those are the documents most likely to have been customised for your business.
