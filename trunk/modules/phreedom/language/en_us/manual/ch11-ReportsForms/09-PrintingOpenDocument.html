Printing a Document You Have Open

Pressing Print on an order, invoice, credit memo, receipt, payment or work order prints the document as it is stored. It does not save it first, and it does not take you away from it — when the print window closes, the document is still on the screen in front of you.

This matters because saving a document is not a harmless act. Saving an invoice removes its journal entry and writes it again, re-costs the stock it moves, and stamps the record as changed. Opening an invoice to take a copy of it should not do any of that, and no longer does.

The print window

Print opens a small window of its own. Where the document type has only one form, that window shows what is about to be printed and how to deliver it: View PDF, Download PDF, or an email panel with the customer's address already filled in where the document carries one.

Where the document type has several forms — several invoice layouts, say — they are listed in that same window, with the first already selected so that printing the usual document takes one click. That first one is simply the one whose title comes first alphabetically; it is not a setting, and renaming a form changes which one it is. The list stays on screen with your selection showing in it, so you can see which layout is about to be used and pick a different one if you need it. Changing the selection fills in the rest of the window, including the subject and message that form supplies for email.

Viewing opens the PDF in a new browser tab, leaving the print window as you left it, so you can look at the document and then still email it without starting again.

Printing several documents at once

Where you have selected several documents — ticking invoices on the Sales Invoice Manager and pressing Print Selected, for instance — they are produced as one document, one after another.

Because it is one document, emailing it sends all of them to whichever address you give. Where the selection is for a single customer, that customer's address is filled in for you as usual. Where it covers more than one, the address is deliberately left blank and the window says so: filling in one customer's address would send them everybody else's invoices. You can still type an address — sending a batch to your accountant, or to yourself, is a reasonable thing to want — but it has to be your decision rather than something the window did for you.

If you have changed something

If you have edited the document since opening it, Print saves your changes first and then prints — there would be no sense in handing someone a printout that disagrees with what is on the screen. A document you have not touched is simply printed.

A document you have never saved is saved first as well: until it has been stored there is nothing to print from.

The Save button

Save greys out while a stored document has no changes waiting. It comes back the moment you alter anything. A greyed Save is not a problem to be worked around — it is telling you that what is on the screen and what is in the database already agree.

Printing without permission to change

Because printing no longer writes anything, it needs no more than the right to see the document. A role set to Read Only for invoices can open one and print it. Roles are set under Company → User Security.

Printing still requires the Forms — run and print documents permission, which is a separate setting on the same page; without it the Print button opens nothing.

The other buttons that leave a document

The same rule now applies to the buttons that carry you from a document to somewhere else — taking a payment against an invoice, exporting a purchase order, stepping to the next invoice with Save and Open Next, or raising a credit memo from an invoice. If you changed nothing, nothing is written on the way out.
