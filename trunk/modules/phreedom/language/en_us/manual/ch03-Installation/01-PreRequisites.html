Pre-requisites

Prior to running the setup script, the following items need to be verified:

System Requirements

During the setup script, FreeBooks will inspect your system and let you know of any missing or downlevel pre-requisites. The setup script will not continue until these pre-requisites are met.

  1. PHP Version: 8.0 or higher (PHP 8.3 is used in the reference Docker image and is recommended)
  2. MySQL 5.7 or higher, or MariaDB 10.3 or higher (the reference Docker setup uses MariaDB 11.4)
  3. Required PHP extensions: pdo_mysql, gd, zip, bz2, openssl, curl, mbstring, and session support
  4. HTTPS is recommended, and is required if you plan to enable passkey (WebAuthn) sign-in — see Passkeys (Passwordless Sign-In)

Chart of Accounts

The installer automatically loads one of four built-in example charts of accounts; there is currently no setup-time option to supply your own. See the chart of accounts help file for details.
