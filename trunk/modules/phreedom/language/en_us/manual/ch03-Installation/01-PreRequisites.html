Pre-requisites

Prior to running the setup script, the following items need to be verified:

System Requirements

During the setup script, FreeBooks will inspect your system and let you know of any missing or downlevel pre-requisites. The setup script will not continue until these pre-requisites are met.

  1. PHP Version: 8.2 or higher, within PHP 8 (PHP 8.5 is used in the published container image, ghcr.io/billj9000/freebooks, and is recommended)
  2. MySQL 8.0 or higher (tested on 8.4), or MariaDB 10.6 or higher (tested on 11.4, which the reference Docker setup uses)
  3. Required PHP extensions: pdo_mysql, gd, zip, bz2, openssl, curl, mbstring, and session support
  4. Web server: Apache 2.4 with mod_rewrite and AllowOverride All. FreeBooks keeps its configuration, company files and logs out of reach of the web with .htaccess files, which other web servers ignore
  5. HTTPS is recommended, and is required if you plan to enable passkey (WebAuthn) sign-in — see Passkeys (Passwordless Sign-In)

Chart of Accounts

The installer asks which of eight built-in example charts of accounts to load (US, UK or Ireland); a chart of your own can be imported afterwards. See the chart of accounts help file for details.
