Test Specification

FreeBooks doesn't have an automated test suite; instead, manual test procedures are maintained as spreadsheets in the TestProcedures/ directory at the root of the source repository (outside trunk/, so this content isn't part of a deployed installation — it's for developers and testers working from the source tree).

PB-TEST-J6-J12.ods

A single spreadsheet containing a full manual regression test plan, organized into sections with individually numbered test cases:

  • Installation — clean install, upgrade.
  • Configuration — company settings, currency, chart of accounts, tax authorities/rates (customer and vendor), custom tabs and fields (inventory and contacts), install/remove, security, permissions, users, roles.
  • Dashboards — adding, removing, and moving dashboards.
  • Contacts — customers, vendors, employees, branches, CRM entries, projects (including copy/rename/delete).
  • Inventory — one test case per inventory type (stock under each costing method, non-stock, master stock, assembly, description, service, labor).
  • Payment and Shipping Modules — one test case per built-in module.
  • Price Sheets — creating and revising customer and vendor price sheets.
  • Every journal (General Ledger, RFQ, PO, Purchase, Vendor Credit Memo, Customer Quote, Sales Order, Sale, Customer Credit Memo, Inventory Adjustment, Inventory Assembly, Cash Disbursement, POP, Cash Receipt, POS) — covering new entries, recurring entries, and conversions between related documents (quote → order → sale, PO → purchase, etc).
  • Banking — reconciliation, bank register.
  • Help, Inventory Tools, the SOAP/ZenCart/OpenCart interfaces, and General Journal Tools (new fiscal year, period changes, chart balance verification, purging).

Several test cases include a detailed worked example with expected values — for instance, a step-by-step inventory costing scenario (purchases and sales in sequence, including an out-of-order edit and a delete) with the expected running average cost, inventory valuation, and income statement impact at each step, used to verify the costing engine calculates correctly.

demo_samples.zip

A companion set of sample CSV files for exercising the import features documented in Importing/Exporting: demo_contacts.csv, demo_inventory.csv, demo_inventory_bb.csv (inventory beginning balances), demo_po.csv, and demo_purch.csv.
