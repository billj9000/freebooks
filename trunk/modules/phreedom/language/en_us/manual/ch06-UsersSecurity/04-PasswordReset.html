Resetting a Forgotten Password

If a user forgets their password, FreeBooks can e-mail them a reset link. The link takes them to a page where they choose a new password themselves. FreeBooks never e-mails a password: the link is the only thing sent, it can be used once, and it stops working after about an hour.

Importantly, requesting a reset does not change or disable the existing password. The current password keeps working right up until the moment a new one is set through the link. This means simply asking for a reset - whether by the user or by anyone else who knows their e-mail address - can never lock a user out of their account.

Resetting your own password

  1. On the login screen, press the Reset Password link.
  2. Enter the e-mail address on your user account and select your company, then press Reset Password.
  3. FreeBooks always shows the same confirmation - "If that e-mail address is registered, a password reset link has been sent to it." - whether or not the address is on file. This is deliberate: it stops the page being used to discover which e-mail addresses have accounts.
  4. Open the e-mail and click the link. It opens a page asking for a new password (entered twice to confirm).
  5. Enter and confirm the new password, then press Set a New Password. You are returned to the login screen and can sign in with it immediately.

Things to know

  • The link is valid for about an hour and can be used only once. After it is used, or once it expires, it no longer works and you must request a new one.
  • Setting a new password through the link also clears any temporary sign-in lockout caused by repeated failed logins.
  • For security, only a scrambled form of the link is ever stored in the database, never the link itself, so the reset cannot be reconstructed from a database backup.
  • If you request another reset within a few minutes of the last one, FreeBooks will not send a second e-mail. Wait a few minutes and try again if the first message does not arrive.
  • If the message does not arrive at all, check the spam folder and confirm the e-mail address held on your account is correct. Reset e-mails also depend on the company's outgoing mail being configured (see the OAuth2 / SMTP setup topic).

Choosing the right company

On a multi-company install, select the company that owns the account before pressing Reset Password. Each company has its own separate list of users, and the reset link is tied to the company it was requested for, so the link opens the correct company's account when clicked - even on a different device that has never signed in to that company before.

Resetting another user's password (administrators)

An administrator does not need the reset-link flow. To set a password for another user directly, open Setup->Users, edit the user, enter a new password in the password field, and Save. Give the new password to the user by a safe channel and have them change it. The reset-link flow described above is for users recovering their own access when they cannot sign in.
