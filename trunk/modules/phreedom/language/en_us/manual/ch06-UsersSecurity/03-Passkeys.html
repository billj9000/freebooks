Passkeys (Passwordless Sign-In)

A passkey lets a user sign in with their device's fingerprint, face scan, screen lock, or a security key instead of typing their FreeBooks password. Passkeys are phishing-resistant - the credential is tied to FreeBooks's own domain, so it can't be tricked into working on a look-alike site - and nothing about it is shared with or stored on the server beyond a public key. Passkeys are an additional way to sign in: the password login is unaffected and always remains available.

Passkeys require the site to be running over HTTPS and a reasonably modern browser. If either isn't available, the passkey option simply doesn't appear and password login works as normal.

Enabling passkeys for a company

  1. Select Company->Configuration.
  2. Find "Allow users to sign in with a passkey" and set it to Yes (this is the default).
  3. The Relying Party ID field below it can normally be left blank - it only needs a value on installs running behind a proxy or hostname that doesn't match the site's configured server URL.
  4. Press Save.

This setting is per company: an install running several companies can allow passkeys on some and not others.

Registering a passkey

  1. Log in with your password as normal.
  2. Select Company->Profile.
  3. In the My Passkeys card, press "Add a passkey".
  4. Enter a name for the passkey (for example "Work laptop" or "Phone") and follow your browser/device's prompt.

A user can register more than one passkey - for example, one for a laptop and one for a phone - and can rename or delete their own passkeys at any time from the same My Passkeys card.

Signing in with a passkey

  1. On the login screen, select the company as normal.
  2. Press "Sign in with a passkey" and follow your browser/device's prompt. No username or password is needed - the passkey identifies the account.

Removing a user's access (administrators)

An administrator cannot register a passkey on a user's behalf - registration always happens on the user's own device - but can revoke one of a user's existing passkeys: open Setup->Users, edit the user, and use the Passkeys card's Revoke button. This immediately stops that passkey working for sign-in; it does not affect the user's password.

Notes for multi-company installs

Passkeys are stored per company, matching how each company has its own separate database. However, if several companies share the same FreeBooks domain (the usual case), the browser's own passkey manager - for example Windows Passkey Manager, or a phone's built-in one - groups all of them together under that one site entry, since it identifies sites by domain rather than by company. To keep them distinguishable there, FreeBooks labels each passkey with both the username and the company name (for example "jsmith — ACME Corp" and "jsmith — Widget Co") at the point it's registered. If two companies happen to show the same name in that list, check that each company's name (Company->Configuration) is actually set correctly and distinctly, since it's what's used for this label.

Deleting a passkey from the My Passkeys card (or having an administrator revoke it) only removes FreeBooks's record of it - it does not reach into the browser or device to remove the credential there, since no such capability exists in the passkey standard. The entry may keep appearing as a sign-in option and will simply be rejected if used. If this is undesirable, remove it from the browser/device's own passkey or password manager as well.
