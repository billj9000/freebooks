VIN Lookup

The VIN Lookup tool retrieves full vehicle details — including the Vehicle Identification Number (VIN) — for a UK registration number, using the same Vehicle Data Global provider that powers postcode lookup elsewhere in FreeBooks.

Vehicle Data Global charges per lookup, so every result is cached locally. Looking up a registration you have already searched returns the cached copy instantly at no additional cost; use Refresh from Provider only when you specifically need up-to-date data.
