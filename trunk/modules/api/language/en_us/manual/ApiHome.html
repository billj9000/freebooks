FreeBooks REST API

The FreeBooks REST API provides read access to your FreeBooks data for external systems such as phone systems, accounting integrations, and data export tools.

The API is a JSON endpoint at /api.php. All requests use HTTP GET with a Bearer token for authentication. Responses follow a consistent {ok, data, meta} envelope.
