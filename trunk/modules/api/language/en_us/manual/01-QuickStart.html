REST API — Quick Start

1. Activate the module

Go to Company → Configuration → REST API. If the module is not installed, install it first from the phreedom admin panel. Once active the api_keys table is created in the company database.

2. Generate an API key

  1. Open Company → Configuration → REST API.
  2. Click Generate New Key.
  3. Enter an optional label (e.g. Phone System or Invoice Export) and click Generate New Key again in the dialog.
  4. Copy the displayed key — it begins with fbk_live_ and is shown once only. Store it securely.

3. Make your first request

All requests are HTTP GET to /api.php with the API key in the Authorization header.

Required parameters on every request:

ParameterExampleDescription
vv=1API version. Currently only 1 is supported.
resourceresource=contactsWhich resource to query. See Resources section.

Example — fetch active customers (curl):

KEY=fbk_live_your_key_here
curl -sg \
  -H "Authorization: Bearer $KEY" \
  'https://your-freebooks-host/api.php?v=1&resource=contacts
    &fields=["id","primary_name","telephone1","email","type"]
    &filters=[["type","=","c"],["inactive","=","0"]]
    &order_by=primary_name asc
    &limit_page_length=50'

Note: The -g flag prevents curl from interpreting [ and ] as range specifiers. Use single quotes around the URL on Linux/macOS.

Example response:

{
  "ok": true,
  "data": [
    {
      "id": "42",
      "primary_name": "Acme Ltd",
      "telephone1": "01234 567890",
      "email": "accounts@acme.example",
      "type": "c"
    }
  ],
  "meta": {
    "limit_start": 0,
    "limit_page_length": 50,
    "count": 1,
    "total": 1
  }
}

4. Retrieve invoices for export

curl -sg \
  -H "Authorization: Bearer $KEY" \
  'https://your-freebooks-host/api.php?v=1&resource=invoices
    &fields=["invoice_number","date","customer_name","total","tax","currency","lines"]
    &filters=[["date","between",["2026-06-01","2026-06-30"]]]
    &order_by=date asc'

The virtual field lines is loaded in a single batch query — there is no N+1 performance penalty regardless of page size.

Requirements

  • HTTPS is required on production. For local development set the environment variable FREEBOOKS_API_ALLOW_HTTP=1 on the web server.
  • The Authorization: Bearer header must be present on every request.
  • All requests must use HTTP GET. The API is read-only in v1.
