REST API — Tax Rates Resource

resource=tax_rates

Read-only lookup of the tax_rate_ids referenced by the Invoices / Credit Memos resources' taxable / freight_taxable fields. FreeBooks' own admin UI (Company Setup > Tax Rates) never displays this numeric id to the user — it only appears inside a hidden onclick attribute on the edit icon — so this resource is the only way for an external integration to discover which id corresponds to which real-world tax.

Fields

FieldTypeFilterSortDescription
idintyesyestax_rate_id — matches Invoices/Credit Memos' taxable/freight_taxable

description_longstringnonoLong label as shown in FreeBooks admin (e.g. 20% VAT on sales)
ratevirtualnonoComputed percentage — see note below
freight_taxablestringnono1/0 — FreeBooks' UI default suggestion for freight on this rate (informational only; the effective per-invoice freight rate is Invoices/Credit Memos' own freight_taxable field, not this one)

Default fields (when fields is omitted)

id, type, description_short, description_long, rate, freight_taxable

Note on rate

A tax_rate_id can combine multiple tax authorities (tax_rates.rate_accounts is a colon-separated list of tax_authorities.tax_auth_id). rate sums their individual rates, the same calculation as gen_calculate_tax_rate() in modules/phreebooks/functions/phreebooks.php — the same one Invoices/Credit Memos' tax_rate/freight_tax_rate fields use.

Example: find the sales tax rates and their percentages

filters=[["type","=","c"]]
