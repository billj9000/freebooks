REST API — Credit Memos Resource

resource=credit_memos

Returns Customer Credit Memos (journal J13) from journal_main. The base filter journal_id = 13 is always applied automatically; callers cannot override it.

The field layout, virtual lines handling, and modified mapping are identical to the Invoices resource — see that page for full field-by-field detail. Only the differences are documented here.

Default fields (when fields is omitted)

id, credit_memo_number, reference, date, customer_id, customer_name, total, tax, freight, currency, closed

Note on the modified field

As with invoices, the journal_main table does not store a row-level last-modified timestamp. The modified field maps to post_date (the credit memo date). Use the date field for range filters.

Note on line item quantity sign

Credit memo line item qty is stored as a positive value (invoices negate qty for inventory draw-down). This does not affect amount or unit_price, which are derived from debit_amount/credit_amount exactly as for invoices.

Virtual field: lines

Include "lines" in the fields array to receive the product line items for each credit memo as a nested array. Summary rows (tax, freight, discount, totals) are excluded; only product lines are returned.

Each line item object contains:

KeyDescription
skuInventory SKU / product code
descriptionLine item description as it appears on the credit memo
qtyQuantity (float, positive)
unit_priceUnit price, computed as amount / qty (6 decimal places)
amountExtended line total (unit_price × qty)
gl_accountGeneral ledger income account code
taxableTax rate ID (0 = non-taxable) — not a percentage; see tax_rate below
tax_ratetaxable resolved to a percentage — see note below

Line items are loaded in a single batch query for the entire page — no N+1 performance impact.

Note on tax_rate / freight_tax_rate

As with invoices: taxable and freight_taxable are tax_rate_ids, not percentages. tax_rate and freight_tax_rate resolve them to the actual percentage FreeBooks would use to calculate tax. Use freight_taxable, not the raw freight_tax_id column, for the effective rate. See the Invoices page for the full explanation.

Example: export credit memos for a date range

fields=["credit_memo_number","date","customer_id","customer_name","total","tax","freight","currency","currency_rate","closed","lines"]
filters=[["date","between",["2026-06-01","2026-06-30"]]]
order_by=date asc

Example: credit memos for a specific customer

filters=[["customer_id","=","42"]]
order_by=date desc
