REST API — Contacts Resource

resource=contacts

Returns rows from the contacts table joined to the main address row for each contact. The “main” address is the row in address_book whose type ends in m (e.g. cm for a customer main address). One row is returned per contact.

Example request including addresses:

fields=["id","primary_name","addresses"]&filters=[["type","=","c"]]

The virtual field is loaded in a single batch query for the entire page — no N+1 performance impact.

Example: caller ID lookup

fields=["id","primary_name","telephone1","telephone2","telephone3","telephone4","type"]
filters=[["inactive","=","0"]]
order_by=primary_name asc
limit_page_length=500

Example: incremental sync (changed since yesterday)

filters=[["modified",">=","2026-07-13"],["type","=","c"]]
