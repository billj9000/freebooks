REST API — Invoices Resource

resource=invoices

Returns Sales Invoices (journal J12) from journal_main. The base filter journal_id = 12 is always applied automatically; callers cannot override it.

Default fields (when fields is omitted)

id, invoice_number, reference, date, customer_id, customer_name, total, tax, freight, currency, closed

Note on the modified field

The journal_main table does not store a row-level last-modified timestamp. The modified field maps to post_date (the invoice date). This is sufficient for date-range export (e.g. “all invoices dated in June”) but does not detect invoices edited after their original posting date. If precise change tracking is required, use the date field for range filters.

Virtual field: lines

Include "lines" in the fields array to receive the product line items for each invoice as a nested array. Summary rows (tax, freight, discount, totals) are excluded; only product lines are returned.

Each line item object contains:

KeyDescription
skuInventory SKU / product code
descriptionLine item description as it appears on the invoice
qtyQuantity (float)
unit_priceUnit price, computed as amount / qty (6 decimal places)
amountExtended line total (unit_price × qty)
gl_accountGeneral ledger income account code
taxable1 if the line is taxable, 0 if not

Line items are loaded in a single batch query for the entire page — no N+1 performance impact.

Example: export invoices for a date range

fields=["invoice_number","date","customer_id","customer_name","total","tax","freight","currency","currency_rate","closed","lines"]
filters=[["date","between",["2026-06-01","2026-06-30"]]]
order_by=date asc

Example: unpaid invoices over £1,000

fields=["invoice_number","date","customer_name","total","currency"]
filters=[["closed","=","0"],["total",">=","1000"]]
order_by=total desc

Example: invoices for a specific customer

filters=[["customer_id","=","42"]]
order_by=date desc
