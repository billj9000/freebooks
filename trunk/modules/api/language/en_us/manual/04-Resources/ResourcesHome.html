REST API — Resources

Each resource is accessed by setting resource=<name> in the request URL. The following resources are available in API v1:

ResourceDescription
contactsCustomers, vendors, employees, and other contacts. Includes all address and telephone data.
invoicesSales invoices (journal J12). Includes line items via the virtual lines field.
credit_memosCustomer credit memos (journal J13). Same schema as invoices, including line items via the virtual lines field.
tax_ratesRead-only lookup of tax_rate_ids referenced by invoices/credit_memos, resolved to their description and computed percentage.

Select a resource from the table of contents for its full field reference.

Additional resources (purchase orders, payments, inventory, etc.) will be added in future releases and will appear in this section.
