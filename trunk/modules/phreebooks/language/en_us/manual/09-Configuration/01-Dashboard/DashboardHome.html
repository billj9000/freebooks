Configuration - Dashboard

Every top-level menu (Company, Customers, Vendors, Inventory, and so on) has its own landing page, made up of dashboard boxes arranged in up to three columns. Which boxes appear, and where, is saved per user and per menu, so each person can build a different dashboard for each area of FreeBooks.

Adding a Dashboard Box

  1. Go to the menu whose landing page you want to customize (for example, click Company).
  2. Press Add Dashboard Items to this Menu.
  3. Check the box for each dashboard item to add. The list shows every box available from the currently installed modules, with its title and a description.
  4. Unchecking a box that's already on the page removes it from the menu, the same as pressing its Remove icon directly on the dashboard (see below).
  5. Press Save.

Arranging Dashboard Boxes

Each box on the dashboard has its own controls in the top-right corner of its title bar:

  • Properties (gear icon) — reveals the box's Move Up/Down/Left/Right buttons, plus any settings specific to that box (for example, how many rows to display).
  • Collapse (minus icon) — hides the box's contents without removing it.
  • Remove (X icon) — removes the box from this menu's dashboard immediately, no confirmation prompt. It can be added back through Add Dashboard Items to this Menu.

Move Left/Right shifts a box into an adjacent column; Move Up/Down reorders it within its own column. A menu can hold up to three columns of boxes.
