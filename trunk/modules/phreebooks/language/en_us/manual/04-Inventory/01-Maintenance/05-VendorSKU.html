Inventory - Vendor SKU

Each row on the Vendor Details tab of an inventory item can record that supplier's own part number for the item, separately from the FreeBooks SKU. This is the number a supplier's own ordering system recognizes, so it is what appears on the Purchase Order screen and what gets used by PO Export Profiles when a purchase order is exported to a file for upload to a vendor's site.

If the Vendor SKU field is left blank for a vendor row, FreeBooks falls back to the first word of that row's Purchase Description. This keeps older items working without requiring every item to be updated, but setting the Vendor SKU explicitly is recommended since it removes any ambiguity about which word in the description is meant to be the part number.

  1. From the main menu, select Inventory->Inventory Manager.
  2. Locate the item to edit and click on the edit icon to advance to the data entry screen.
  3. Select the System tab and locate the Vendor Details section.
  4. For the row belonging to the vendor whose part number you want to record, enter the number into the Vendor SKU field. Add a new row with the Add icon if the vendor is not already listed.
  5. When all desired fields have been entered, press Save to save your information and return to the inventory edit/maintain window.

NOTE: The Vendor SKU is shown read-only on Purchase Order line items, resolved live from the item record - it is not something typed directly into a purchase order.
