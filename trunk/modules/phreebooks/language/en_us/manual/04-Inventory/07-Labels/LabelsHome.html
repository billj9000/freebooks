Inventory - Label Printing

FreeBooks includes a label printing module for printing product/barcode labels for inventory items. A label template controls both the physical size of the label and its content, which can include the item's SKU, a CODE128 barcode, and a QR code, in addition to plain text fields such as description, price, cost, UPC and weight. Templates can render either as HTML (printed through the browser or a QZ Tray-connected label printer) or as ZPL (sent directly to a Zebra-compatible thermal printer through QZ Tray).

Creating a Label Template

  1. From the main menu, select Inventory->Label Templates.
  2. Press New.
  3. Enter a Template Name, and the label's Width (mm) and Height (mm).
  4. Select a Printer Type:
    • HTML (browser / QZ Tray) — the label is built as an HTML fragment. Enter it in the HTML Template box.
    • ZPL (thermal/Zebra) — the label is built as raw ZPL and sent to the workstation's default printer through QZ Tray. A separate ZPL Template box appears when this type is selected.
  5. Build the template using the placeholders listed under Available Variables:
    {{ sku }}Item SKU / part number
    {{ description }}Full item description
    {{ short_description }}Short description
    {{ price }}Formatted retail price
    {{ cost }}Formatted item cost
    {{ upc }}UPC code
    {{ weight }}Item weight
    {{ barcode_svg }}CODE128 barcode SVG encoding the SKU (HTML templates only — use {{ barcode_svg | raw }})
    {{ qrcode_svg }}QR code SVG encoding the SKU (HTML templates only — use {{ qrcode_svg | raw }})
    {{ pack_qty }}The Pack Qty value entered on the Print Labels page/popup
  6. Press Preview at any time to render the current HTML Template against sample data.
  7. Press Save.

NOTE: Managing label templates (creating, editing, deleting) and printing labels are controlled by two separate permissions, so a user can be allowed to print existing labels without being able to change the templates.

Printing Labels

There are two ways to print labels for an item:

  1. From the main menu, select Inventory->Print Labels. Search for the item by SKU or vendor part number (type at least 3 characters), select it from the results, choose a Label Template, set the Pack Qty (the value that fills the {{ pack_qty }} placeholder on the label) and the Number of Labels to print, then press Print Labels.
  2. From the Inventory Manager list or an item's edit screen, press the printer icon (Print Label / Print Labels) on the item's row or toolbar. This opens the same print options in a popup, pre-filled with that item's SKU.

What happens next depends on the selected template's Printer Type:

  • HTML templates open a new browser tab containing one label per page and trigger the browser's print dialog automatically.
  • ZPL templates are sent through QZ Tray to the workstation's default printer. QZ Tray must be installed and running on the workstation for ZPL printing to work; if it isn't detected, an error is shown instead of a print job.

Editing or Deleting a Label Template

  1. From the main menu, select Inventory->Label Templates.
  2. Press Edit on the template's row to change it, or Delete to remove it.
