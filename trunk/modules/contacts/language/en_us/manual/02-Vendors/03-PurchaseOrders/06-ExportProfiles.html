Purchase Orders - Export Profiles

Some vendors accept purchase orders uploaded to their own ordering system as a file, rather than by fax or email of a printed PO. An Export Profile describes the line format that vendor's system expects - for example, a simple file of one line per item reading vendor part number;quantity - so a purchase order can be downloaded in that format directly from the PO screen. Each line is built from the vendor's own part number for the item (see Vendor SKU), resolved fresh at export time so the file always reflects the current item record rather than whatever was on the order when it was saved.

Creating an Export Profile

  1. From the Vendors Menu, select Purchase Orders, then PO Export Profiles.
  2. Press New.
  3. Enter a Profile Name and, if the vendor requires something other than a plain text file, a File Extension.
  4. Enter the Line Template - the text repeated for every item on the order, with placeholders substituted per line. The most common template is {vendor_sku};{qty}. Available placeholders are {vendor_sku}, {sku}, {qty}, {description}, {cost}, {line_no} and {package_qty}.
  5. If the vendor's format requires a header or footer line, enter a Header Template and/or Footer Template. These accept {po_number}, {po_date}, {vendor_name}, {account_number}, {line_count} and {total}. Any placeholder not recognized is left blank rather than causing an error.
  6. Select the Line Ending the vendor's system expects (Windows/CRLF or Unix/LF).
  7. Press Save.

Assigning a Profile to a Vendor

  1. Open the vendor's account and select the General tab.
  2. Select the profile from the PO Export Profile pull-down menu, next to Default Currency.
  3. Press Update to save the vendor account.

Exporting a Purchase Order

  1. Open the purchase order to export.
  2. Press the Export icon in the toolbar. The purchase order is saved first, exactly as when printing.
  3. The file is generated and downloaded by the browser using the vendor's assigned profile.

NOTE: If the vendor has no Export Profile assigned, or if any line item has no Vendor SKU that can be resolved, the export is stopped and the affected items are listed so they can be corrected before retrying.
