Vendors - Status

There is no separate status screen for a vendor. A vendor's active/inactive state is a single Inactive checkbox on the vendor's General tab.

When checked, the vendor is excluded from the default vendor list (a Show Inactive option on the list toggles them back into view) and its row is highlighted when shown alongside active vendors. Checking Inactive does not delete any history or prevent existing transactions from referencing the vendor — it only affects whether the vendor appears in day-to-day lists and lookups.
